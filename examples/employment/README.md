# 就业情况分析 · 示例任务

一个「领域」示例：让 agent 读真实统计数据，写出一份经得起核对的分析报告。

## 数据

- `data/wages_2025.csv` —— 国家统计局《2025年城镇单位就业人员年平均工资情况》
  表 2 的逐字转载：19 个行业门类 + 合计，2025 年 / 2024 年 / 名义增长率。
- `data/sources.md` —— 来源链接、统计口径、已知缺口。

**口径提醒**：这是「城镇非私营单位」的年平均工资，含个税社保公积金，
不含个体工商户与自由职业者，所以它高于多数人到手工资。写报告必须写明这一点，
否则数字会被误读。

## 要交的东西

在工作区里写出 `report.md`（Markdown），必须包含：

1. 一句话结论（这 19 个行业的薪资格局是什么样）。
2. 数据口径说明：城镇非私营单位、不含个体户、平均工资含代扣代缴。
3. 完整排名表：19 个行业 ×（2025 年平均工资、名义增长率），从高到低。
4. 三条发现，每条都要带具体数字：
   - 最高薪行业是谁、多少；
   - 最低薪行业是谁、多少，两者差几倍；
   - 增长最快的行业是谁、多少；哪两个行业负增长、各降多少。
5. 有多少个行业高于全国合计（129441 元）。
6. 给求职者的三条建议——必须从上面的数字推出来，不许写空话。

## 判分

判分脚本 `_check.py` 在**工作区外面**（`examples/employment/_check.py`），
agent 读不到它的期望值，改不了它。它查的是：数字对不对、该点的行业有没有点、
该算的倍数算没算。退出码 0 才算过。

## 怎么跑

```powershell
$py = "E:\.venv\FastAPIProject7\.venv\Scripts\python.exe"
& $py run.py run `
  --goal "读 data/ 里的统计数据，写一份 report.md：19 个行业薪资排名、三条发现、对求职者的建议" `
  --project "D:\autoflux\examples\employment\data" `
  --check ("`"{0}`" `"D:\autoflux\examples\employment\_check.py`"" -f $py) `
  --max-steps 25
```
